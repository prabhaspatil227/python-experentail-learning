# Word Jumble Game (Python)

A beginner-friendly command-line word puzzle game.

## Features
- Randomly scrambled words
- Three attempts per round
- Optional hints
- Score tracking (up to 10 points per round)
- Five rounds per game
- Option to play multiple games
- Avoids repeating words within the same game when possible

## Requirements
- Python 3.8 or newer
- No external packages required

## How to run
1. Extract `Word_Jumble_Game.zip`.
2. Open a terminal or Command Prompt in the extracted folder.
3. Run:

   ```bash
   python main.py
   ```

   On some Windows installations, use:

   ```bash
   py main.py
   ```

## How scoring works
- Correct on first attempt: 10 points
- Correct on second attempt: 7 points
- Correct on third attempt: 5 points
- Using a hint reduces the points earned by 2 (minimum 1 point)
- Incorrect after all attempts: 0 points
